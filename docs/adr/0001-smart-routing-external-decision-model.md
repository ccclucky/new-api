# 智能路由用外部决策模型（Jev），每轮独立、池取交集、失败兜底

智能路由让客户端用虚拟模型名 `auto` 调用，网关把请求最后一条 user 消息（截断）发给外部决策模型 Jev（TypeSafe AI System One，封闭答案分类器，非转发网关），答案集即候选池内模型名，top-1 直接采纳。选外部决策模型而非网关内规则/自训分类：接入最小、成本极低（输入 $0.042/MTok、输出免费）、效果有校准分数可后验。明确否决的备选：问复杂度再本地映射（多一张难维护的映射表）、把 Jev 伪装成渠道（语义不符、增耦合）。

刻意不做：会话粘性（每轮独立路由，零状态；若体验割裂再复用 channel_affinity）；置信度阈值（失败才兜底，不看分数）；成本上限（候选池 = 分组全部模型 ∩ token 允许模型，无档位限制；真出问题再加「路由最高档」一个字段）。

边界与安全：功能全局开关且默认关——用户内容发第三方必须有显式同意；Jev 不可用/超时/答案越池时退回全局配置的兜底模型，请求绝不因路由器失败；决策结果与兜底原因记入用量日志，响应 `model` 回填真实模型，按真实模型计费。
